# Sitio web de CMR (Creative Maximum Reasoning)

Sitio estático oficial de **Creative Maximum Reasoning**, desarrollado con una estética editorial en **negro oscuro mate** y diseñado para el dominio `cmr-reasoning.com.ar`.

## Estructura de Archivos

```
index.html                     → Página de inicio oficial (Hero, Apps, Sobre el autor, Contacto)
apps/cmr-writer-lite.html      → Subpágina de la aplicación CMR Writer Lite
assets/
  ├── images/                  → Logotipos y encabezados oficiales de CMR
  └── favicons/                → Favicons en múltiples resoluciones (.ico)
```

## Directrices de Identidad & Anti-Slop de IA

El diseño del sitio sigue estrictamente la guía de estilo documentada en [`../../doc/directrices-diseno-identidad-cmr.md`](../../doc/directrices-diseno-identidad-cmr.md):
- **Paleta Negro Oscuro Mate:** `#0a0c10` (fondo), `#10141d` (superficies), `#151a26` (tarjetas), acentos en oro antiguo `#c99738`. Cero fondos blancos encandilantes.
- **Tipografía Editorial:** `Fraunces` para títulos y carácter literario, `Inter` para cuerpo y `JetBrains Mono` para datos técnicos.
- **Cero Clichés de IA:** Sin orbes neón, sin emojis en píldoras, sin textos hinchados ni plantillas genéricas.

## Cómo probar localmente

Hacé doble clic en `index.html` para abrirlo en cualquier navegador web. Todos los enlaces son relativos y no requieren dependencias externas de compilación.
