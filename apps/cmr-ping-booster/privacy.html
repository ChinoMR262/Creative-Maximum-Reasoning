01 Titularidad y Alcance Legal

El presente documento establece las condiciones de privacidad y especificaciones técnicas para la aplicación móvil CMR Ping Booster (Package ID: com.cmr.pingbooster), desarrollada bajo la autoría y titularidad exclusiva de Jonathan Gabriel Nieto para la marca y entidad Creative Maximum Reasoning (CMR).

02 Tratamiento de datos y consultas DNS

CMR Ping Booster no recopila ni almacena datos personales, historial de navegación o consultas DNS en servidores de CMR. Para prestar la función de resolución, las consultas DNS necesarias se envían directamente al resolver público seleccionado por la persona usuaria. Ese proveedor aplica su propia política de privacidad:

  • Datos Personales: No se solicitan nombres, cuentas, correos electrónicos, agendas de contactos, localización GPS ni identificadores únicos de hardware (IMEI/MAC).
  • Consultas DNS: CMR no recibe ni almacena consultas DNS en servidores propios. Las consultas necesarias salen del dispositivo hacia el resolver público seleccionado, que aplica su propia política de privacidad.
  • Infraestructura: La aplicación no opera servidores proxy comerciales ni almacena registros (logs) de conexiones en la nube.

A efectos de la taxonomía de Google Play, esta transferencia efímera se declara de forma conservadora como Navegación web → Historial de navegación web. Esto no implica que CMR cree o conserve un historial: CMR no recibe esos datos y la consulta se transmite al proveedor DNS público elegido para devolver la resolución solicitada.

03 Declaración de uso de VpnService

La aplicación declara el siguiente uso de android.permission.BIND_VPN_SERVICE:

FINALIDAD TÉCNICA:

La API VpnService crea una interfaz local (TUN 10.254.1.2) que procesa consultas DNS. La app prioriza DNS-over-TLS autenticado hacia el proveedor seleccionado; si la red lo bloquea, puede usar DNS estándar sin cifrar con ese mismo proveedor para conservar la conectividad. El resultado depende de la red, el proveedor y la ubicación; no se garantiza una reducción de ping o microcortes.

Aclaración: CMR Ping Booster no es una VPN remota, no oculta la IP pública y no envía tráfico general a servidores de CMR. Sí procesa los paquetes DNS que Android dirige a la interfaz local y los reenvía al resolver elegido. El tráfico web y de juego no DNS conserva la ruta habitual de Android.

03A Mediciones de red y proveedores externos

El radar y algunos diagnósticos realizan conexiones TCP a los destinos mostrados y consultas DNS al resolver elegido; una comprobación DNS puede consultar google.com. Cuando la persona solicita medir descarga, la app prueba Cloudflare Speed Test y, si hace falta, Tele2. Esos servicios pueden recibir la dirección IP y los metadatos de conexión necesarios para responder y aplican sus propias políticas. La medición del radar o del resolver no es el ping del servidor del juego.

CMR-ADB puede descubrir servicios de Depuración inalámbrica mediante mDNS en la red local y conectarse al dispositivo emparejado para ejecutar acciones que la persona solicita. La búsqueda y conexión solo se usan al abrir o usar las funciones de CMR-ADB; Android puede mostrar un permiso de acceso a la red local.
