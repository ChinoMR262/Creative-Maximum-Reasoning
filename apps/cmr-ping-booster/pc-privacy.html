01 Titularidad y Naturaleza del Software

CMR Ping Booster para PC es un software de optimización de entorno y estabilidad de red desarrollado de forma autónoma bajo la autoría de Jonathan Gabriel Nieto para Creative Maximum Reasoning (CMR).

Se distribuye como una aplicación portable de 64-bit para Microsoft Windows 10 y Windows 11. No requiere instalación de controladores intrusivos de bajo nivel (drivers de kernel) ni servicios persistentes en segundo plano que afecten el rendimiento del equipo.

02 Política de Integridad y Cero Riesgo Anti-Cheat

La premisa fundamental de CMR Ping Booster para PC es garantizar la compatibilidad absoluta y el cero riesgo de baneo o sanción en cualquier plataforma de videojuegos competitivos en línea:

PRINCIPIOS TÉCNICOS DE NO-INTRUSIÓN:
  • Cero Acceso a Memoria: El software nunca solicita identificadores de proceso con permisos de lectura o escritura (PROCESS_VM_READ / PROCESS_VM_WRITE).
  • Cero Inyección de Librerías: No se inyectan archivos DLL, no se utilizan hooks en la tabla de direcciones de importación (IAT) ni se modifican los ejecutables de los juegos.
  • Compatibilidad Total: Funciona armónicamente junto a sistemas de seguridad como Riot Vanguard, Easy Anti-Cheat (EAC), BattlEye, Valve Anti-Cheat (VAC) y Activision Ricochet.

Todas las optimizaciones se limitan a funciones documentadas del sistema operativo: ajuste de precisión del reloj multimedia de Windows (timeBeginPeriod(1)), liberación de memoria residual no utilizada mediante EmptyWorkingSet, y optimización de resolución DNS Anycast local.

03 Sistema de Actualización Directa Integrada (In-App Auto-Update)

Para mayor comodidad de los usuarios de cualquier provincia o región, el programa cuenta con un mecanismo de auto-actualización directa dentro de su propia interfaz de usuario:

¿CÓMO SE ACTUALIZA EL PROGRAMA DE PC?

  1. El usuario abre la pestaña Ajustes dentro de la aplicación y presiona el botón "🔍 Buscar Actualizaciones".
  2. El servicio consulta de manera segura y transparente el buzón central de versiones en GitHub Pages (version.json).
  3. Si existe una versión más reciente, el programa habilita el botón "⬇️ Descargar e Instalar Ahora", mostrando el progreso de descarga porcentual en vivo.
  4. Al completarse la descarga, el programa ejecuta un script atómico seguro, reemplaza el ejecutable en su misma ubicación y relanza la aplicación actualizada al instante, preservando todas las preferencias.

Este proceso es 100% transparente, no descarga instaladores adicionales de terceros ni requiere permisos de administrador invasivos.

04 Privacidad Cero-Datos y Operación Local

Al igual que la versión móvil, CMR Ping Booster para PC opera bajo una política rigurosa de cero recolección:

  • Sin Cuentas ni Registros: No se requiere iniciar sesión, crear credenciales ni proporcionar datos personales.
  • Sin Telemetría Oculta: No se envían estadísticas de juego, listas de programas instalados ni historiales de navegación a ningún servidor.
  • Sin Publicidad: La interfaz está libre de banners comerciales, módulos de monetización y rastreadores de terceros.

05 Reversibilidad Inmediata y Salida Limpia

El programa fue diseñado para no dejar residuos en el sistema:

  • Al desactivar el modo de juego o cerrar la aplicación desde la bandeja del sistema (System Tray), se invoca inmediatamente timeEndPeriod para restaurar el temporizador estándar del reloj de Windows.
  • Se restablece la configuración DNS del adaptador de red activo.
  • No quedan procesos secundarios ni servicios residentes en memoria.
