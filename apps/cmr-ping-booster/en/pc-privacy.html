01 Ownership and Scope of PC Edition

CMR Ping Booster for PC is a native desktop gaming optimization tool created under the sole authorship of Jonathan Gabriel Nieto for Creative Maximum Reasoning (CMR).

Distributed as a portable 64-bit standalone executable for Microsoft Windows 10 and Windows 11. It operates without kernel-level device drivers or persistent background daemons.

02 Zero Anti-Cheat Risk Guarantee

The core technical foundation of CMR Ping Booster PC is complete compatibility and zero risk of penalties or bans across competitive multiplayer anti-cheat engines:

NON-INTRUSION TECHNICAL PRINCIPLES:
  • No Memory Access: Never opens handles requesting process read or write rights (PROCESS_VM_READ / PROCESS_VM_WRITE).
  • No Library Injection: Injects no dynamic-link libraries (.dll), applies no Import Address Table (IAT) patches, and modifies no gaming binaries.
  • Universal Anti-Cheat Compatibility: Safely coexists with Riot Vanguard, Easy Anti-Cheat (EAC), BattlEye, Valve Anti-Cheat (VAC), and Call of Duty Ricochet.

All system tuning relies on documented Win32/UWP APIs: Multimedia Timer resolution locking via timeBeginPeriod(1), passive memory compaction via EmptyWorkingSet, and local Anycast DNS socket tuning.

03 Direct In-App Auto-Update Mechanism

For users across any province, region, or network, the PC client features a self-contained in-app updater:

HOW DOES THE PC UPDATE PROCESS WORK?

  1. The user navigates to the Settings tab and clicks "🔍 Check for Updates".
  2. The service performs an authenticated HTTPS lookup against the central GitHub Pages version manifest (version.json).
  3. If a newer release exists, the client activates "⬇️ Download and Install Now", reporting real-time percentage progress.
  4. Upon download completion, an atomic batch script gracefully swaps the executable in-place and relaunches the updated client with all user settings intact.

This process requires no manual file copying, no third-party installers, and no registry pollution.

04 Zero-Data Policy & Local Execution

Consistent with the mobile architecture, the Windows PC edition collects zero information:

  • No Accounts: No registration, login, or personal profile required.
  • No Telemetry: Gaming telemetry, process lists, and hardware IDs are never transmitted.
  • No Ads: Clean, commercial-free interface without third-party tracking scripts.

05 Complete Reversibility & Clean Exit

The application leaves no residual footprint:

  • Exiting via the System Tray immediately triggers timeEndPeriod to return the Windows scheduler to its default power-saving state.
  • Original network adapter DNS assignments are restored cleanly.
  • Zero zombie processes remain in execution.
